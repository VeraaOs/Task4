# Task4
Написать свою обёртку над FixedThreadPool. Эта обёртка должна исполнять ShutdownableExecutor. Померить FixedThreadPool против тех, которые написаны в файле.
Попробовать написать функцию blackHole(long difficulty). Функция должна производить вычисления, сложность который линейна от difficulty. Заменить sleep на blackHole и померить все executor'ы ещё раз. результаты и мысли(если будут) разместить в комменте рядом с кодом.


Я сделала разбор логов последовательно и параллельно. В параллельном варианте файлы читаются потоками из пула. Есть семафор, атомарные счётчики, остановка через volatile и обработка битых файлов/строк.

Если строка битая, пропускаю её и считаю как повреждённую. Если файл не читается, он помечается как ошибочный, остальные продолжают обрабатываться. При досрочной остановке в отчёт попадает всё, что успели обработать, плюс флаг остановки.

Что должно выполняться:
- строка обрабатывается один раз;
- число запросов равно сумме успешных и ошибок;
- максимальное время не больше суммы всех времён;
- активные файлы не превышают лимит семафора;
- после завершения активных файлов 0;
- один битый файл не ломает остальные.

Дедлока нет, потому что порядок фиксированный: сначала семафор, потом чтение, потом статистика. Никто не ждёт семафор, удерживая блокировку. Освобождение семафора и завершение задачи — в finally. volatile нужен, чтобы рабочие потоки сразу видели флаг остановки.

Эксперименты на 16 файлах по 50 000 строк (800 000 строк). Параллельный результат совпал с последовательным, значит записи не теряются. 4 потока быстрее одного: 722 мс против 1142 мс. Семафор 4 быстрее семафора 1: 548 мс против 1150 мс. Статистика по отдельным адресам лучше общей, если адреса разные. Если почти всё идёт в один адрес, разница небольшая: 532 мс против 394 мс.

Битые данные видны в счётчиках, но не портят отчёт. Досрочная остановка работает: часть данных остаётся, активных файлов в конце нет.

Ограничения: замеры разовые, без медиан. При остановке итератор не закрывается явно, хвост может закрыть сборщик мусора.
